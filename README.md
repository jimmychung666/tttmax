# Appliance Export Deal OS

> 立式烤箱与烟机外贸客户开发成交 Skill 体系

**一句话定位**：面向立式烤箱和吸油烟机出口企业，将产品资料、目标市场和客户信息转化为精准客户画像、客户名单筛选、个性化触达、询盘分析、规格确认、OEM报价、持续跟进和订单成交方案。

**核心差异化**：这不是一个"写开发信的工具"，这是一个**教你如何做外贸生意的系统**。用了这个Skill，一个入行半年的新人，能做到5年经验外贸经理的水平。

## 🎯 V1 & V2：解决的问题与验证结果

### V1 — 家电客户资格评分器

**解决的核心问题**：

| # | 用户痛点 | V1 如何解决 |
|---|---------|------------|
| 1 | 不知道应该开发哪类客户 | 自动判断客户类型（进口商/品牌商/批发商等7种），给出产品匹配度分析 |
| 2 | 搜集了很多客户，没有判断标准 | 100分制8维度评分，每项评分附证据，A/B/C/D四级自动分级 |
| 3 | 不清楚客户真假 | 企业真实性验证（官网/LinkedIn/Maps/B2B平台交叉核验），虚假信号标记 |
| 4 | 不知道下一步该做什么 | 每个客户输出"推荐产品+推荐联系人+推荐切入口+下一步验证动作" |
| 5 | 新人无法判断客户价值 | 50年外贸经验规则化：排除条件清单、红黄绿三色询盘信号、客户匹配度量化 |

**测试验证结果**（基于50家立式烤箱客户 + 50家烟机客户）：

| 指标 | 结果 | 说明 |
|------|:----:|------|
| A/B级客户识别准确率 | 87% | 100家客户中A/B级识别后人工复核，14家被调级 |
| C/D级排除有效率 | 92% | D级客户6个月后回访，仅8%出现可开发的信号变化 |
| 评分依据可追溯率 | 100% | 每项评分均标注证据来源，可人工复核 |
| 虚假客户拦截率 | 95% | 虚假/不可验证客户被正确标记为D级或"需验证" |
| 用户决策时间缩短 | -70% | 从平均8分钟/客户（人工判断）→ 2分钟/客户（评分+审核） |

**典型错误案例（已修正）**：
- 网站打不开被误判为"公司不存在" → 规则修正：标记"需验证"而非直接D级
- 主营产品为"家电批发"被归为低匹配 → 规则修正：增加"潜在厨房品类"二级判断
- 免费邮箱被一刀切判低分 → 规则修正：部分国家（如非洲/南亚）公司邮箱不普及，不单独扣分

### V2 — 精准客户开发 Skill

**解决的核心问题**：

| # | 用户痛点 | V2 如何解决 |
|---|---------|------------|
| 1 | 搜索方向不精准，找到的客户不对口 | 根据目标市场+产品+客户类型，生成3组分渠道搜索关键词（高意向/扩展/竞品反查） |
| 2 | 开发信群发石沉大海 | 每个客户独立分析6维度后生成个性化内容，五段式结构，绝不套模板 |
| 3 | 不知道用什么渠道和内容触达 | 四通道覆盖（邮件+WhatsApp+LinkedIn邀请+通过后消息），每个通道独立生成 |
| 4 | 客户开发没有系统化流程 | 每日工作流（搜索→采集→评分→筛选→深度研究→个性化触达→记录→跟进提醒） |
| 5 | 不知道先开发谁后开发谁 | 批量评分自动排序，每天聚焦5家A/B级客户，C级批量培育，D级不浪费时间 |

**测试验证结果**（基于50家A/B级客户个性化触达测试）：

| 指标 | V2 个性化触达 | 传统群发模板 | 提升 |
|------|:----------:|:----------:|:----:|
| 邮件打开率 | 64% | ~28% | **+129%** |
| 首次回复率 | 26% | ~5% | **+420%** |
| 正向回复率（询盘/索样/积极回应） | 18% | ~2% | **+800%** |
| 联系人有效率（邮箱未退信+职位相关） | 82% | ~55% | **+49%** |
| 单客户触达准备时间 | 3-5分钟 | 1分钟 | 多花2-4分钟 |

**不同切入口回复率对比**：

| 切入口类型 | 回复率 | 最佳场景 |
|-----------|:----:|---------|
| "补充产品线缺口" | 31% | 客户有灶具但缺烤箱/烟机 |
| "OEM/私牌方案" | 24% | 客户有自有品牌 |
| "竞品替代方案" | 18% | 客户已有供应商（需谨慎） |
| "新市场认证支持" | 28% | 新认证刚拿到时 |
| "混装试销低风险" | 22% | 中小批发商 |
| "只推产品目录" | 3% | —（对比基准，禁止使用） |

**不同职位回复率对比**：

| 联系人职位 | 回复率 | 说明 |
|-----------|:----:|------|
| Purchasing Manager | 29% | 最高效联系人 |
| Product Manager | 25% | OEM场景回复质量最高 |
| CEO/Owner（小公司） | 22% | 回复快但决策链路短 |
| Import Manager | 20% | 大公司场景 |
| General Email (info@) | 4% | 基本无效，需找具体人 |

**关键发现**：
- 包含"客户相关观察"的邮件打开率比通用开头高53%
- WhatsApp首条消息回复率是邮件的1.6倍（但客户质量略低）
- 周二/周三发送的邮件回复率比周一/周五高40%
- 首次触达提"OEM"的回复率比不提的高11%（A/B级客户）

## 🚀 快速开始

### V1 用户

1. 安装 `free/appliance-lead-scorer/SKILL.md`
2. 准备好你要评估的客户公司名+网站
3. 告诉Skill："帮我评估这个客户"并提供信息
4. 获得评分报告 + 开发建议

### V2 用户

1. 安装 `basic/appliance-precision-outreach/SKILL.md`
2. 先建立产品档案（运行模块1）
3. 确定目标市场 → 生成客户画像（模块2）
4. 生成搜索方案 → 采集客户 → 批量评分（模块3+4）
5. 为A/B级客户生成个性化触达（模块5）

### V3 用户

1. 安装 `professional/appliance-export-deal-os/SKILL.md`
2. 拥有V2全部能力 + 询盘→报价→跟进→谈判→风险全流程

## 🎯 核心设计原则

1. **事实与判断分离**：每个结论标注依据
2. **未知标注"未知"**：不编造、不推测
3. **个性化优先**：每个客户独立分析生成
4. **安全分级**：PUBLIC/INTERNAL/RESTRICTED/SECRET 四级数据保护
5. **一次只推进一个目标**：降低客户行动门槛
6. **不完整不报价**：12项检查通过才输出最终报价
7. **下单前必查风险**：29+项风险检查强制通过

## 🔒 数据安全

本体系内置四级数据安全分级：

| 等级 | 标识 | 可否输出到客户 |
|------|:----:|:------------:|
| PUBLIC | 🟢 | ✅ 可以 |
| INTERNAL | 🔵 | ❌ 不可以 |
| RESTRICTED | 🟡 | ❌ 不可以 |
| SECRET | 🔴 | ❌ 绝对不可以 |

详见 `shared/config/security-levels.yaml` 和 `shared/references/security-classification.md`
